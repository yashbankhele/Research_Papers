## About the project

The system takes user inputs such as destination, budget, trip duration and number of travelers, and generates a personalized itinerary.

- AI-generated itineraries using the Google Gemini API
- Hybrid recommendation logic (rule-based + AI) based on popularity, cost, distance and weather
- Interactive route and hotel maps using OpenStreetMap and Folium
- Real-time weather information
- Hotel booking with Razorpay payment integration
- AI chatbot for travel queries
- Django backend with an SQLite database

**Project code:** [ai_trip_planner_and_recommendation_system](https://github.com/yashbankhele/ai_trip_planner_and_recommendation_system)
